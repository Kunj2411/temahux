# SEO-IMPLEMENTATION.md

Complete record of the SEO implementation for TEMAHUX.

---

## Current SEO Architecture

**Framework:** Next.js 16.3.8 (App Router, Turbopack)
**Rendering:** Static generation (SSG) for all public pages; server-rendered for admin/dynamic routes
**Canonical domain:** `https://www.temahux.com`
**Structure:** One Next.js app serving three sites via route segments:
- `/` — Main TEMAHUX experience (3D WebGL + static fallback)
- `/services` — TEMAHUX Services
- `/academy` — TEMAHUX Academy

## Canonical Strategy

- Every page uses `alternates: { canonical: "..." }` in its metadata
- Root canonical: `https://www.temahux.com/`
- Services canonical base: `https://www.temahux.com/services`
- Academy canonical base: `https://www.temahux.com/academy`
- No www/non-www conflicts (all canonicals use `www`)
- `metadataBase` set to `https://www.temahux.com` in root and academy layouts
